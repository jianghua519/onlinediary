## 项目概述
家庭多用户日记应用,参考Day One设计,支持端到端加密,部署在Synology DS216+上,支持外网访问。

## 核心功能需求

### 1. 用户认证与权限
- 用户名密码注册/登录
- 首个注册用户自动成为管理员
- 管理员可以:
  - 批准新用户注册(可选开启审批模式)
  - 查看系统用户列表(不能查看他人日记)
  - 管理存储空间配额
- 会话管理(JWT + Refresh Token)
- 记住登录状态(30天)
- 密码修改功能

### 2. 端到端加密机制
- **加密流程**:
  - 用户注册时生成主密钥(从密码派生,PBKDF2)
  - 主密钥加密用户的私钥,私钥存储在服务器
  - 每篇日记用随机AES-256密钥加密
  - 日记密钥用用户公钥加密后存储
- **实现**:
  - 所有加解密在浏览器端完成
  - 服务器只存储加密后的数据
  - 密码忘记 = 数据永久丢失(需明确警告用户)
- **性能优化**:
  - 加密操作使用Web Crypto API
  - 大文件分块加密

### 3. 日记编辑功能
- **自定义日期**
  - 默认当前时间
  - 可手动选择任意历史日期
  - 可精确到小时分钟
  - 阻止未来日期(可配置)
- **富文本编辑器**
  - Markdown语法支持
  - 实时预览
  - 格式工具栏:标题、粗体、斜体、引用、代码块、列表
  - 图片拖拽上传
  - 图片自动压缩(前端压缩后再加密)
- **元数据**
  - 标题(可选,默认取首行或日期)
  - 标签(多标签,自动补全)
  - 天气(手动选择图标)
  - 位置(文本输入)
  - 心情(emoji选择器)
- **自动保存**
  - 输入停止3秒后自动保存草稿
  - 草稿也加密存储
  - 离线编辑缓存在IndexedDB

### 4. 日记浏览与管理
- **视图模式**
  - 时间线视图(瀑布流卡片)
  - 日历视图(月历,有日记的日期标记)
  - 列表视图(紧凑)
  - 标签云视图
- **搜索与筛选**
  - 全文搜索(客户端解密后搜索)
  - 多标签AND/OR筛选
  - 日期范围选择器
  - 按心情/天气筛选
- **操作**
  - 编辑/删除(带确认)
  - 星标收藏
  - 批量操作(批量删除、导出)
  - 导出格式:加密ZIP、纯文本Markdown、PDF

### 5. 数据同步与离线
- **实时同步**
  - WebSocket连接(心跳保活)
  - 编辑时实时推送更新给其他设备
  - 冲突检测:版本号 + 时间戳
  - 冲突解决:提示用户手动选择保留版本
- **离线能力**
  - Service Worker缓存应用壳
  - IndexedDB存储最近100篇日记
  - 离线编辑加入同步队列
  - 在线后自动同步队列
- **多设备通知**
  - 同一账号其他设备在线时提示"有新日记"

### 6. 附件管理
- **图片**
  - 支持格式:JPG, PNG, GIF, WebP
  - 前端自动压缩(长边最大2048px)
  - 加密后上传
  - 缩略图生成(客户端)
- **限制**
  - 单篇日记最多10张图片
  - 单张最大10MB(压缩前)
  - 每用户存储配额(默认5GB)

## 技术架构

### 前端技术栈
```
React 18 + TypeScript
├── 状态管理: Zustand
├── 路由: React Router v6
├── UI组件: Tailwind CSS + shadcn/ui
├── 编辑器: Tiptap v2
├── 加密: Web Crypto API + crypto-js
├── 本地存储: Dexie.js (IndexedDB)
├── 实时通信: Socket.io-client
├── 日期处理: date-fns
├── 图片压缩: browser-image-compression
└── PWA: Workbox
```

### 后端技术栈
```
Node.js 18 + TypeScript
├── 框架: Express.js
├── 数据库: MariaDB 10 + Sequelize ORM
├── 实时通信: Socket.io
├── 认证: jsonwebtoken + bcrypt
├── 文件存储: 本地文件系统(加密文件)
├── 限流: express-rate-limit
├── 日志: winston
└── 进程管理: PM2
```

### 部署架构
```
外网访问
  ↓ (HTTPS)
Synology DSM反向代理 + Let's Encrypt证书
  ↓
Node.js应用 (端口3000)
  ├── Express API服务
  ├── Socket.io服务
  └── 静态文件服务
  ↓
MariaDB 10 (端口3306)
  └── journal_db数据库
  ↓
文件系统
  └── /volume1/journal/uploads/ (加密文件)
```

## 数据库设计

### users表
```sql
CREATE TABLE users (
  id CHAR(36) PRIMARY KEY,
  username VARCHAR(50) UNIQUE NOT NULL,
  password_hash VARCHAR(255) NOT NULL,
  email VARCHAR(100),
  public_key TEXT NOT NULL,
  encrypted_private_key TEXT NOT NULL,
  is_admin BOOLEAN DEFAULT FALSE,
  storage_quota BIGINT DEFAULT 5368709120, -- 5GB
  storage_used BIGINT DEFAULT 0,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  last_login TIMESTAMP,
  settings JSON,
  INDEX idx_username (username)
);
```

### entries表
```sql
CREATE TABLE entries (
  id CHAR(36) PRIMARY KEY,
  user_id CHAR(36) NOT NULL,
  encrypted_title BLOB,
  encrypted_content BLOB NOT NULL,
  encrypted_metadata BLOB, -- tags, weather, mood, location
  encrypted_entry_key BLOB NOT NULL, -- 用用户公钥加密的日记密钥
  entry_date DATETIME NOT NULL, -- 用户自定义的日记日期
  is_favorite BOOLEAN DEFAULT FALSE,
  version INT DEFAULT 1,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE,
  INDEX idx_user_date (user_id, entry_date),
  INDEX idx_user_favorite (user_id, is_favorite)
);
```

### attachments表
```sql
CREATE TABLE attachments (
  id CHAR(36) PRIMARY KEY,
  entry_id CHAR(36) NOT NULL,
  encrypted_filename BLOB NOT NULL,
  file_path VARCHAR(500) NOT NULL, -- 加密文件存储路径
  encrypted_file_key BLOB NOT NULL,
  mime_type VARCHAR(100),
  file_size BIGINT NOT NULL,
  thumbnail_path VARCHAR(500), -- 加密缩略图路径
  uploaded_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  FOREIGN KEY (entry_id) REFERENCES entries(id) ON DELETE CASCADE,
  INDEX idx_entry (entry_id)
);
```

### sync_queue表 (同步队列)
```sql
CREATE TABLE sync_queue (
  id INT AUTO_INCREMENT PRIMARY KEY,
  user_id CHAR(36) NOT NULL,
  entry_id CHAR(36),
  operation ENUM('create', 'update', 'delete') NOT NULL,
  data JSON,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  processed BOOLEAN DEFAULT FALSE,
  INDEX idx_user_processed (user_id, processed)
);
```
